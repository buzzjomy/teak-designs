# Teak Designs

A clickable demo storefront for solid teak furniture from the forests of Kerala and Tamil Nadu.

- Home page, category browsing, filters and sorting
- Product pages with finish preview and a pincode delivery check
- Cart drawer and a mock checkout

**This is a prototype.** Products, prices, ratings and policies are sample content. No orders are placed and no payments are taken. Product images are AI-generated for demonstration.

## Run locally

Open `index.html` in a browser. No build step is needed.

## Files

- `index.html`: the whole storefront (HTML, CSS and JavaScript)
- `img/`: product photos (`p*.jpg` full size, `t*.jpg` thumbnails)
